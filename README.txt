SPOTTR — GHID DE ACCES ȘI PREZENTARE

VARIANTA ONLINE (GITHUB PAGES)
Aplicația: https://1x1x-del.github.io/spottr-demo/
Codul: https://github.com/1x1x-del/spottr-demo
Deschide linkul aplicației în Chrome, Edge, Firefox sau Safari, pe laptop ori telefon. Vizitatorii nu au nevoie de cont GitHub. Contul 1x1x-del gestionează codul și publicarea. Linkul Emergent nu mai este necesar pentru această demonstrație.
Pentru o copie din GitHub: pagina codului > Code > Download ZIP; extrage arhiva și deschide index.html.

VARIANTA DIN ARHIVĂ
1. Descarcă Spottr-demo-pentru-prezentare.zip pe laptop.
2. Click dreapta pe arhivă > Extract All / Extrage tot.
3. Deschide folderul extras și dublu-click pe DESCHIDE-SPOTTR.html.
4. Dacă Windows întreabă cu ce aplicație: alege Chrome, Edge sau Firefox.
Nu deschide fișierul direct din interiorul ZIP. Nu trebuie instalat nimic și nu este necesar un server. Pentru telefon recomandăm linkul online.
Pagina și funcțiile demonstrative sunt incluse în HTML. Harta schematică funcționează fără internet. Harta stradală și Google Maps necesită internet; localizarea depinde de permisiunile browserului și poate să nu funcționeze din fișierul local.

UTILIZARE — DEMONSTRAȚIE ÎN 3 MINUTE
1. Intră la Parcări. Caută Unirii; poți filtra facilitățile și sorta rezultatele.
2. Selectează parcarea și apasă butonul de rezervare demo.
3. Alege ora de început și 2 ore. Folosește numărul fictiv B 123 DEM. Confirmă.
4. Intră la Rezervările mele. Arată durata și totalul simulat. Prelungește cu o oră și confirmă.
5. Arată anularea și istoricul. Poți exporta rezervările ca fișier text.
6. Deschide Asistent auto și un scenariu, de exemplu Martor în bord.
7. În Despre proiect explică limitele și integrările necesare unui produs real.
Înainte de o prezentare nouă: Despre proiect > Resetează rezervările demo > Confirmă.

CE FUNCȚIONEAZĂ ȘI CE ESTE SIMULAT
34 de parcări în setul demonstrativ, căutare, filtre, hartă schematică și hartă stradală opțională, rezervări locale, prelungire, anulare, istoric și export. Nu se rezervă locuri reale, nu sunt afișate disponibilități în timp real și nu se încasează bani. Tarifele și informațiile despre parcări nu sunt validate pentru utilizare reală. Asistentul folosește răspunsuri pregătite; nu este conectat la un serviciu AI și nu pune diagnostice.
Rezervările se păstrează numai în browserul folosit, dacă acesta permite stocarea locală. Nu se sincronizează între telefon, laptop, site și arhivă. Modul privat, ștergerea datelor browserului sau mutarea fișierului pot pierde istoricul. Folosește exclusiv date fictive.
Nu sunt necesare chei API, card sau abonament pentru această versiune. Nu activa servicii cu plată pentru demonstrație.

ÎNTREȚINERE
Fișierul index.html din GitHub conține întreaga aplicație. La actualizare se înlocuiește acest fișier și se salvează un commit; GitHub Pages publică noua versiune. Arhiva este copia de rezervă pentru prezentare. Arhiva separată Spottr-cod-recuperat-2026-10-08.zip păstrează materialele recuperate din proiectul inițial și nu este pachetul de pornire rapidă.
